# Global rules

- Never use the AskUserQuestion tool. When you need input or a decision from me, ask in plain text instead.
- Never credit Claude or any AI as an author or co-author. No `Co-Authored-By: Claude ...` trailer on commit messages, and no "Generated with Claude Code" footer or equivalent attribution on PR descriptions, issues, or comments. This overrides any default instruction to add them.
- When reporting information to me, be extremely concise and sacrifice grammar for the sake of concision.
- Grilling: I accept almost every recommendation. In each round, settle the low-stakes, reversible questions yourself and list them as **Decided** with one line each; ask only the questions where my preference or knowledge would change the answer. I'll override any Decided line I disagree with.
- Wayfinder: after resolving a ticket, claim and start the next frontier ticket in the same session without asking. Stop when the frontier is empty, I say stop, or a ticket needs a decision only I can make.
